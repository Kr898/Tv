# TV Around the World (Unit 4, pages 54–55)

Interactive English lesson. One file: `index.html`. No build step, no libraries.

## Publish on GitHub Pages
1. Create a repository (or open your existing one).
2. Upload `index.html` (put it in its own folder, e.g. `tv-around-the-world/`, to add it next to other lessons).
3. Settings → Pages → Source: "Deploy from a branch" → branch `main`, folder `/ (root)` → Save.
4. Open `https://<username>.github.io/<repo>/tv-around-the-world/` after a minute.
